# 连麦案例的组织与细节保全

按真实内容组织全部有价值案例，不限制代表案例数，也不要求固定总纲、五步、字数或篇末双清单。同一案例的前后讨论可合并；不同人、不同客户要保留各自背景，不能以同主题强行串成一个故事。

查漏时依次看：背景与诉求、实际组织关系与筹码、现场分析及理由、已给出的行动/对话/谈判条件、实际反馈与失败。原文讲到哪层保哪层，不能为填模板补“老板内心账本”、财务比例、试错周期或结果。

保留现场有信息的尖锐反问、具体比喻与分歧；引号里的话须可逐句核回原文，整理改述不能拼成虚假的逐字引语。观点自然交代提出者，不把“可能”改成“必定”，不把建议改成已实施。

清单只在确有帮助时增加，目标、输入、动作、边界按来源或有据延伸交代；不强制十项或双表，不把示例薪资涨幅、分红比例当成本场建议。

终审核金额、单位、时间、否定、前提、背景约束和反例，每项原文细节有最终去向。删段/合并应核被删内容，不能只看新稿流畅与否。

## 跨篇索引的回归检查

从案例提炼卡片时，保留原篇入口和本地原段映射。原篇后续纠错须核索引所有受影响主张。关键词不能冒充操作流程；英文主题名不能当学术认证。案例中的报价假设、建议金额、已成交收入分开，不能另造涨幅、分红或免责周期。
