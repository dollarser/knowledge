# 2026-11-14 · 企智 AI 落地派第 1 场直播知识

## 集团派人给子公司做 AI，先问谁能动生产流程

一位做过制造信息化的集团 IT 员工，在原项目组解散后被安排到子公司调研 FDE，也就是深入客户现场做业务落地。跑了一两周，他发现子公司愿意让集团看合并报表和分红，却未必让集团派来的人碰生产。集团看见降本机会，子公司才掌握工艺、班组和权限。如果没有人肯说真实需求、给试点环境、决定谁来改流程，派人过去也不等于项目启动。他计划月底离开原集团，另找一份主业，再从自己熟悉的制造环节找一笔明确订单，把调研到交付走一遍，有了样品再去直播间演示找反馈。

## MES 定制和模型工具分开卖，入门课用来认识客户

一支原本做定制 MES、ERP 的团队，要按不同工厂的生产、质检和供应商协作习惯写软件，已有的 MES 仍用传统开发。另一路 AI 生意用简单课程引流，将模型 API 接到明确流程上，打包成桌面软件或 SaaS，按电脑或项目收费。客户按用途选模型、自己补用量，开发方说自己赚软件和交付费。讨论中一台部署几千元、大客户可能部署十来台是团队的报价举例，MCP 接 MES 是别人的追问，当时并未实现。眼下这支团队更缺会讲课的人，开发小工具反而有经验。

## 用低价产品先试投流，再分出学习和企业交付两条成交路

做过 Excel 内容的团队把直播和短视频的获客方法搬到了 AI。机构号依赖团队运营，个人号对台前的人依赖重，团队担心员工走了也带走影响力。投流先看前端低价产品能否回收流量费，再分两条后续路径。想学的人可从线上课走到线下，提过接近两千、三千和四千元的档位。企业老板想直接用，就入企调研并报交付范围。他们以前也用引流、培训带 MES 和 ERP 项目，只是匹配客户不多，不能把前端有观看或报名直接算作企业订单。

## 大单收了首款，仍要把需求反复和尾款算进去

这支团队自报普通单有一两千到四五千元，大单也谈过五六万元。他们更喜欢几天能结束的小单。过去几万乃至十几万元的开发，首款进来了，需求却改得久，尾款和工程师的时间一并拖住。报价时把服务器、开发、后续维护拆开，讲清议价和增项的节点。过去也有十万元开发再加每年约一万元运维的单子，现在有人接受较低开发费再按服务收钱。现场的月产值和同时服务多少家属于算例，接单时还是要用自己的修改工时、续费和实际到账来判断。

## 员工学会操作和开发商改系统，是两种培训

企业先确认要用的软件，再教员工按自己的生产流程操作。财务、法务等业务骨干可以先学怎么给 Agent 业务上下文、怎样检查结果，并不必从编程语言学起。要自己用 Agent 改大型软件的人，得知道前端、后端、字段和数据库的关系。云仓入库识别规格的例子里，团队负责训练和维护，员工只走基本操作。现场提到过从六成向九成改的阶段，但没有同口径评测。稳定工作尽量用确定的程序执行，生成内容等确实需要判断或创意的环节再接模型。

## 线下课的讲师能跨城，三千元内的学员未必肯跑远

培训团队先看本地有没有足够多的学员，再安排获客和交付。讲师可跨城，学员未必为几千元的课额外付差旅。现场按六七天、一间教室约四百元一天和三十人报名做过收入场地粗算，没算退费、投流、助教与差旅。前端主播或销售负责说明课程，老师讲概念、带着学员做题。做过授课的人举每天上午、下午各两小时，留时间现场辅导。老软件老师未必会智能体，程序员未必会教，能把学员教会的产品经理也可试讲。有人靠老学员转介绍招生，讨论过数字人代讲，但互动和辅导能否接得住仍是问题。

## 给商品一张图和几句剧情，做三十到五十秒的短剧广告

做广告工具的人把古风、穿越等剧情先做成模板，客户选风格、上传商品图，再写几句文字，目标是让商品成为短剧里的道具或情节。团队称先走贴牌验证渠道，再考虑自有品牌和代理。口头说的上千个贴牌没有讲清计数口径，不能用作企业成交量。有人另建议自己投信息流，尚无结果。

## 检测报告先把手记、部位和统一表格对上

机构现场手记测量数据，回来要按统一格式，把检测物、部位和数字填好、出报告签字。朋友做过初稿，体验没到预期。如果只服务自己且模板固定，可以先把表格规则写成重复使用的 Skill，找真实记录测试漏填、错位。计划卖给不同机构并按年收费时，就要问各地模板和审批流程是否一样、哪些功能需要模型、何时值回调用费。共创和买断都没敲定。另有人想把摄像压力观察产品代理给学校，先要确认既有客户、相近工具和使用权限，谈话没有证据支持识别率或筛查用途。

## FDE 平台做得七八成，第一批人来了为什么会留下

有人做了两端：企业发需求，专家写自己擅长的行业和案例，再选能做的项目。他估计技术完成七八成，最没把握的是谁愿意首批来和双方怎样建立信任。安装后即卸载、熟人捧场活跃，都可能让数据好看。比下载更能说明问题的是有没有真实需求和真实对接。另一支杭州、苏州的团队通过网络认识流量与技术伙伴，再互访确认能做什么，据分享已在内测并开始接触伙伴，不能当作前一平台的进度。

## 函证和尽调先解决一个能复查的任务

做过十多年财务尽调的人做了个桌面 Agent，称已有手机、桌面和网页五端，少量同行试用。考虑聊天、会议和日志之前，更具体的任务是发函、收函、填清单和逐项复核。扫描 PDF 歪斜或模糊时，先放大查阅、显示报告重点与中间结果，让审计员知道在哪里确认。没有公布识别准确率和收费。

工具用一个 Markdown 入口按任务调用细分 Skill，当前资料区让客户上传并点选引用，还没有通用审计知识库。用 DeepSeek API，在客户自有算力条件具备时才探讨换本地端点。另有人建议将有授权的失败案例纳入行业资料库，和现在上传自己的项目文件是两回事。卖硬件前可先拿一个能演示的任务，找十到三十个潜客试流程，确认有需求再花时间打包设备。

## 月维护费卖给客户的是哪些服务

一位 FDE 给交付客户讲基础使用并收月维护费。另一个做小企业知识库的人称客户自备消费级主机，他配置本地工具和 Skill，举过三万元部署加每月两千维护的项目。谈续费可先把版本更新、问题处理、培训和安全维护说清楚。有人每月免费培训一次，允许已服务客户带自己的客户来，靠实际解决问题形成转介绍。工具或 Skill 都能有替代，续费最终看业务是否有人跟。为了试客户，可以在直播直接演示实事，明确接定制还是接套模板。接口先花半小时或一小时试可调性，确定有客户再找工程师实施。也有人从本地 OPC 活动接触同行和潜客，见面和补贴传闻都不能算订单。

## 医疗算法工程师靠行业文章接到第一笔标书服务

做了约十年算法的人平时定义问题、搭模型、带团队、跟论文，也做技术公众号和视频。他的系列文章被医院博后看到，对方付费请他修改国自然标书，金额不多。过去帮科研人员做课题，小项目自报累计挣过几十万元。其中乳腺方向有老经验，换到肺癌项目虽然收到钱，却要重新吃透业务，为发表目标投入很大。再换疾病要重学，同行会安防检测或者 NLP 也未必能听懂医生并完成研究要求，所以他暂缓扩张。

现场给他的做法是把能承接的事写进文章，在职时先找精准客户和产品伙伴。做医疗的朋友能从超声、CT 的售后带回问题，再由工程师判断能不能建模。有人讲过发现可能漏筛、通知回院、复查确认的经历，但疾病名称前后不清，没有临床效果数据。这个经历说明他为何愿继续做医疗，不能用来推荐临床筛查服务。

## GPT 单张图答对，和两千万条卡片里搜对不是同一任务

这位工程师还遇到交易卡客户扫卡出错。客户拿 GPT 单张问图成功来比较。工程团队面对的是大量卡片、实际响应时间和重复检索，现场举约五秒单问和两千万条数据库来解释差别。比较效果要用同一批难例和实际流程。工程师也观察到职责从清洗、训练、调参向调用 API 移动，但仍担心出了错能不能控制。换用 API 前，仍需看垂直目标检测、推荐或特定数据任务要什么。

## 能演示的 Demo 和长期可维护的产品之间，有一笔真实工程账

算法工程师遇过客户自己做出 Demo，再找人把它变成产品。比如工作流能剪视频、接到表单，只验证了几个步骤，稳定性、异常恢复、费用和维护要按后续需求另算。有人把这类机会叫软件修复。前面一位开发者曾调用可灵做图片对口型，因当时约一元一秒的用法太贵而停充；要把垂直视觉做成可售 API，还要准备训练数据、标注和设备。医疗数据另有院内、伦理及权限条件。切入维修还是深做医疗，取决于已有客户和能否扛住跨行业重学的时间。

## 南京商会免费课做第一场验证，课后按门店真实需求分单

一位电商操盘者入行约二十天，和南京商会接洽免费课。她之前在当地活动讲过“员工用了 AI，为什么公司效率没上来”，打算按商会成员行业选演示，用问答收集店老板实际卡点，自己负责找客户，本地 FDE 或技术伙伴做可行的部分。比如老板的日常看板希望看到每日账、损耗、利润、进出货，对门店营销则先搞清是餐饮到店团购，还是广告设计等行业留资、承接、回访。

推广建议从餐饮、酒店行业群找会长、副会长或熟悉会员的人。南京先把 PPT、授课演示和后续承接跑过一次，再考虑长沙和郑州。长沙伙伴有餐饮酒店资源、擅长落地，郑州有人已免费教过 Codex 并提供课件，异地分工仍在谈。弹幕有酒楼两次踩坑的反馈，没交代问题细节。有人建议短视频、本地推、直播团购券配合，值得先选一个门店试，不能算已成交打法。

## 门店内容包先说清图文、视频、发布和用量怎么结算

一方建议用 Codex 配 Skill 准备小红书、美团、大众点评、视频号的文案和图文，商家审后再发，设想月费约三百元，视频另议。商会操盘者关注的是抖音、视频号的门店 IP，设想先做自己的知识库，按店家信息生成口播、选形象和场景、混剪，已经在试把角色放进场景走动讲话。提过两三千元方案，对照其所见的拍摄文案月服务五千到一万元，客户用量另算。通用贴牌素材没解决如何起号，运营者想把自己做过的参数和素材搭配经验放进模板。弹幕提过三十九元课教 Codex 下载、使用和做 Skill，附现成 Skill，有购买者还没下载。课程、给图文、长期代运营是三种交付，预算、返佣和分工要分别问明。

## 小游戏先上已有用户的平台试玩法，再补自己的分发

开发者已做出带积分的网页样品，不确定玩法和推广。另一方自报做了三十三款，只有一款约一千六百次游玩，别的大多几十或几百。先借已有观众的平台看会不会玩、能否回来，再决定要不要自建。用短视频演示手感或核心动作，音乐节奏、热点题材和受众差异逐个观察。WebGL 是网页 3D 选项，Google Play、iOS、Steam 是不同形态的上架讨论。短平快网页玩法和一次性卖断独立游戏不应用同一套渠道。跑出重复流程后再抽引擎，独立发布则另算并发、服务器和引流。

## 青少年 AI 课在纸上设计之前，先分清学生要学什么、谁付钱

青少年班还在想，当前正尝试的是商会企业课和本地生活。过去接触机构的人观察到初高中更看技术基础、学业和能否做小作品，大学生较有兴趣问就业、商业，且初高中学生可分出的时间短。家长付费、孩子使用，学校有助触达并不代表家长肯报。先核实际需求和老师能否把场景讲明白，再谈寒假班等产品。找新需求还可看招聘平台在招哪些任务，用岗位线索去问对方的工作内容和预算，单靠招聘频次不能判断市场体量。

## 跨境客户要的是少切会话，还是把一家店交给你运营

一位重庆游戏公会从业者在海外获客时，要来回切 Facebook 和 Instagram 的多个工作账号，想在一个界面里看到会话，产品不过贵就愿意试。这个需求已经具体到操作，但没有购买。另一方设想按每店每月约四千元做 Amazon 代运营，以现有人力一万五至两万元每月作对比。两者完成的工作不同，钱不能直接相减算利润。先问客户是要增加产出，还是减少重复操作，接手哪些步骤、每周交出什么，再看代运营值不值得做。

## 法国寿司店先用自己的菜品和店面试做几条素材

法国南部工业商圈的寿司店，中午主要是办公室和工业区员工，晚上还有附近居民。他家点单形态与附近自助餐不同，口味也本地化。当地团队拍摄和沟通方便，每月报七八百欧，店主试过效果不理想。已有员工在维护 Instagram 定位，店主想用自家菜品引流，试过通用餐饮剪辑又不贴合。可先用真实菜品和店内图或视频，按目标客人调图生视频、剪辑、配文案，让 Reels 等短视频能指向具体门店。Codex 搭流程、试 TikTok 和 YouTube 是建议，要比较最终到店、法语本地化和拍摄成本，没给出已跑通的实现。

## GEO 先把品牌料和可发布的平台整理好，用真实询盘验

工具作者拿自家酒店管理系统先试，反馈有人经豆包问价、开始试用，没披露成交。用真实企业资料做品牌库，再据此生成内容。把搜索提交、B2B、行业网站、地方网站、论坛等来源分清，整理可发布的范围，遇审核和人工确认的地方留给人做。作者称网页和客户端已做，另有收集失效和新增网址入口，并接了付费媒体接口，未核覆盖数。客户若没官网，可先做真实公司和产品资料的集中页。查成效要用客户会问的话、对比品牌词和非品牌词是否可见，最后数真实咨询。单场豆包询问不能推到其他平台，异地检测仍在设计。

做技术课的另一支团队有网站，但此前接单主要靠展会和自办活动，个别专业词能搜到不等于线上能稳定来询盘。可先测网站能否被搜到、行业长尾问法有没有结果，再试 GEO，海外适用还没研究。工具可自助、客户自付模型用量，也可把资料整理和发布运营分别计费。服务商有既有建站或 SEO 业务时，可能比工具方独自承接每家客户更近现场。按有效线索计费需要约好何为线索、归谁、什么条件结算。提到新能源车潜客要先整理资料、两三天试流程，目前没有付费或成效记录。曾用生成工具做宣传站和策划的细部产品名口播不一，不能据此写实现方法。

## 采购模型接口，先试你将来真的会用到的任务

算力方找 GEO 工具方谈过提供模型接口。工具当时自述用豆包与 DeepSeek 的官方接口，还未换到聚合商。试用时拿自己的材料和负载去测，问测试环境与长期供应是否一致，失败和服务可用性怎么约。弹幕追问 SLA 如何执行也是同一个问题。价格、折扣和供货说法没有合约证据，别把单段对话当可用供应商清单。做外部托管基础设施也有类似成本问题：有人追问报价明细才发现托管方利润很薄，算燃料的单位有效产出还要加上运维、保险、运输储存、环保和并网条件。

## 医疗 Agent 是查证、记录还是训练，要分清三类用途

讨论以 OpenEvidence 举例说明怎样从医学指南和研究找依据，以 Abridge 举例说明怎样把诊室对话生成结构化记录草稿，交医生检查。SOAP 是病历记录结构，ICD 和 CPT 分别涉及诊断及操作服务编码，不能因为模型能整理文字就让它作临床决定。有人声称可接触多年连续病历，想评估本地微调，仍得核数据授权、合同、脱敏处理和第三方审核，资金只是有条件的讨论。云端托管 Agent 与本地部署的差异，是谁管运行环境、数据留在哪里。弹幕提到 Claude Managed Agents 可以作为选型线索，并未现场核过具体权限。另一位想做消费端玩具，需要健康和案例资料，和病历微调不是同一个项目。弹幕还提到的好伴 AI 在本段指医疗产品。

## 硬件黑客松，先把外壳和控制原型分别打样

一位做了十年产品的人要试一件温热干预止鼾硬件，用 3D 打印做外观，以 ESP32 开发板验证功能。以前这类项目多接别人 SDK，这次用嘉立创的选型及打样链路缩短准备。弹幕问到 PCB 打版和 SMT 贴片，没说这次实际订了哪些服务。样机是功能试验，不能据此宣称止鼾效果。黑客松也可以看真实软件和硬件样品、找动手伙伴，但有的活动偏招商，和实际共同开发不是一回事。

## AI 操作 Office 和 CAD，从实际流程、结果与预算问起

传统行业需要在 Office、CAD 等已有工具上少做重复动作。一些人试过 UiBot、影刀，也有人试让模型写 RPA 代码、把动作整理成 Skill，或让 Agent 调用带接口的自动化。八爪鱼由弹幕提到，现场没给试用结果。只自动执行确定动作时，脚本和 RPA 也许已经够用。有人说用 Skill 做过 CAD，没展示具体交付。部分几分钟的人工任务，参与者称烧了几百元模型调用还没跑完；订阅是否更省也要按同一个任务、同样的成功率重测。企业要额外验证错误会不会改数据、谁复核，以及查询和更新是否分离，别直接拿生产库试。讨论时先给一项具体操作、预期输出和预算，比问“哪款 Agent 好”有效。

## 咨询公司交 U 盘时文件已分好，问题是下个项目找不回来

一个咨询项目设想帮助驻场咨询师提速。客户不缺项目，缺的是能派到现场的人，以及把旧项目的经验留给下一批咨询师的办法。文件按项目存 U 盘，分类还算整齐，缺统一检索。先问咨询员怎样找旧方案、访谈和交付范例，哪些只是按关键词查，哪些需要按客户、岗位、流程关系追溯。向量相似检索能协助找资料，结构化关系能帮助串业务对象，各自按需求加。项目有过百余页 PPT、十余类工种，从三个月缩到两个月只是目标。录访谈须先获授权。考虑以 AgentScope 做框架，让现有 IT 接手，尚未正式启动。

同场提醒，安装桌面工具、知识库和几个智能体可做演示，进企业做 FDE 还要调查资料、权限和谁维护。医疗 HIS 销售是另一个例子：销售曾先说可以做，技术后来才发现做不到。客户的需求应先复现，再由商务确认能承诺什么。有企业订阅约五万元一年的说法只是一位朋友的个案。

## 企业选模型和硬件，要在自己的设备和任务上试

有人所在企业用 DeepSeek 和 GLM，一些项目还要求设备来源满足内部条件。试过进口卡又找国产卡，自己的任务尚未跑顺，也提过用 AMD 的例子。测试要用真正要跑的输入、输出和整机，不能凭榜单或一次安装经历给整类硬件定性。另一块知识产权垂直模型业务，自述约半年盈利、约三百客户，服务过程和获客路径没有展开。企业销售有人觉得小商家沟通容易，也有人认为没明确需求的公司教育成本高，各自遇到的客户不同。

## 直播公会先自动通知新人今天做什么

一位公会运营者给八人左右的小组上线第一版。过去用手敲新主播第几天该做什么，现在上班前自动把当天安排和开播提醒发过去，员工到岗后可找 PK 对手。老板出服务器和域名，运营者说已签书面的咨询试点服务协议，每月数千元咨询费与岗位工资分开。上月的约六千万音浪是业务量，不能换算成这套工具赚的钱。原先安排耗时约一两小时来自经验，自述增长也没做归因。

后续设想才包括拍视频建议、跟播时按评论给话术、下播维护和分机构知识库。行业共用的新人任务做成流程，各机构自己填赛道术语。每月两万元订阅和节约四成员工是设想。老板提过，小组跑通且业绩有提升，再考虑全公司推广或买断。另有一位参与者用口述称为 DSH / DeepSeek Harness 的工具，把常用操作做成可以随手拉开的侧栏插件，再由主控调用其他模型。公会没有确认使用这套工具。公会运营者也曾用 ChatGPT 排 Python 学习进度，每天练到能写简单程序，先保留主业再验证新服务；此前有 TikTok 跨境项目，合伙公司亏损后退出。医院销售经理则说大客户维护仍在线下，想从内部报表和资料入手，老板偏买成熟工具，她的自建提议未获采用。

## 深圳灯饰厂先看能不能卖，小服务先挂单测需求

一个灯饰厂有货和库存，没卖出去，说明有供给也得先试销售和营销。另有人把 OpenClaw 本地部署当明确小服务挂闲鱼和淘宝，自报标价约 29.9 元、千余单，也卖过约 9.9 元一张的生成图。这些是其当时的报价和订单口述，未说退款、交付工时和利润。能学的是先把一次交付说清楚，再看有无第一批真实购买。

## 动漫情感短视频工作台，按钮能开网页不代表会交片

做过素人账号的人想让工作台每天找方向、理解参考片、写本频道脚本，然后把文案与授权图像、音频合成能继续编辑的草稿，发布可由本人完成。她拿 Codex 和豆包试过，页面能启动，概览和账号数值还是示意，官网入口能打开抖音，真正的业务 API 没接。看到的成片有一张图播很久的，也看到过六个分镜，配音与词还可以，分镜未达到要求。她还说聊天一个月，没拿到一篇能直接用的稿。先找一条自己有权用的素材，看脚本、分镜、图、声音和剪辑草稿能否交齐，再验多条。把频道参考、格式和规则放项目资料，避免每次聊天重讲，向量库仍是计划。

如果只是请人花两小时排查，可以先谈诊断费用。需求不明，可以先按天合作，等成片和接口要求确定再按结果报价。有人估几百元诊断、两三天修改，双方未成交。自己的电脑能常开时可先本地试，持续联网和多人访问再考虑服务端。做内容最终还要接上后端。她想用关系议题的优质短视频吸引明确人群，再转给自己能对接的真人服务。另一位谈的轻陪伴原型尚未商业化，不能承诺解决个人关系问题。

## 动漫视频拆成文案、图、动态镜头和剪辑，按镜头算钱

另一位创作者把授权文案提炼亮点，再让不同 Agent 出图、图生视频，最后进剪辑。完全重生成和带着原素材做混剪，控制办法、权利条件和费用都不一样。有人先把十几二十元说成四分钟，随后纠正是约半分钟。现场以 0.5 元一秒算四分钟 120 元只是算例，报价还要按实际生成秒数、重做、人工审片比较。长片分成十三四秒再拼接，会增加衔接和剪辑时间。即梦、Seedance 出现在工具讨论，未确认具体版本或现价。简单火柴人内容可以先试 PPT 式分镜或让豆包分析画面形式、在 WorkBuddy 做草稿，与重生成视频分别比较。没有核过显卡和内存，不据此判断本地能跑多大任务。另一位需求方提到自己第一次整理知识库，可把学习资料和生活资料分区，和业已部署的短视频工作台无关。

## 提点子也能成为合作贡献，收入比例却得落合同

有位不写代码的参与者在线上和开发者聊了约三个月，交流产品想法与业务，没有参与实现。产品拟很快送测，对方提出以后从总收入里留比例给她，没谈比例、合同、付费用户或到账。她过去也从直播平台获得项目机会，有些从未见过对方。另一位做付款交割的人每笔都要问款能否收回。这两类合作需要的信任检验不一样，分成更不能只当一句感谢。

## 用自家猫狗照片做桌宠，先看用户愿不愿把它留在桌上

做过 C 端销售的人想避开成品库存、转订单化虚拟产品，难在找愿意谈需求的人。朋友觉得手机就能装宠物，没必要再带设备。她的设想是工作时不能陪真猫狗，用户输入自家照片，做一个像旧版 QQ 宠物那样能摸头互动的桌面成品，买的是可爱和情感投入。数字样可以先验相似度和互动，后续再考虑用闲鱼找羊毛毡作者做外壳，放芯片做实物。她计划拍短视频在小红书展示，另有人说自己积累了四千多名潮玩客户，提议用自己已有的动漫角色测试。两条素材和渠道都可以先低成本试。目前没有销量或技术定案。另一位做自动化的人让豆包出过四个方案，现场未展示。聊到香插时，客户想指定认得的款式，可以试找标明款式的明盒，所见香插可能是二创，未核系列名或现货。

另一位把桌宠作为自家动漫 IP 的宣发，希望角色能在屏幕上陪伴用户。他的团队还试过拍几集动画，费用高、没赚钱，暂时搁着；商品、音乐、吉祥物和系列剧的结合属于以后想做。从小样了解有没有受众，比启动长系列轻。

## 亚马逊铝板画卖成头部，漏算人工仍会一单亏五六十美元

接电商的人先向老板和财务索要全成本，半个月没拿到，只拿到进料单。她把大板尺寸、裁出的小板规格和采购价交给 GPT，请它生成各规格的材料成本表，再查 Amazon 同款平均价格定价。按材料看售价翻了几倍，把公司人力纳入账才发现单笔亏约 50–60 美元。据她说是头部款，日卖约五六百件。当地生产的货有一单要等约一个半月，工序提到裁剪、CNC 和上色；没有完整费用表，不能补上运费、平台费或良率。

老板还考虑独立站、实体门店。她从竞品看到联名和艺术家合作的高客单选择：对方出图，工厂用自己的材料和加工做成品。有人来厂询问投资，未成交。团队争的是先把单位成本降到能赚钱再放量，还是在自己能承担的范围内先投品牌。她退出原项目后，利润分成影响奖金；有人建议碰不到成本账时谈按销售额分，没谈成。她另写工业产品电商、独立站和供应链整合计划，老板和 eBay 官方开过会，尚无订单。想试 OPC 时，两位有经验的软件、硬件同事可以补位。需求还没跑通，可按任务付费合作，长期分工、股权和亏损承担要另谈。

## 用共享文件夹传 Agent 命令，先确认哪一边真收到了

试验中用 Codex 把命令写入共享文件夹，WorkBuddy 能收到，其他工具不行，企微机器人也没接通。是否端口未开还没查明。有人提定时扫描文件、用飞书多维表格或 MQ 发消息；如果不想后台一直轮询，可先验证事件是否能主动投递。此前让 Codex 按 MQ 做过一次，做偏。找到的飞书 SDK 是对接工具，不能当成整套飞书服务端源码；团队目标只是把自己用的几个通信功能做轻。

另一个试验要把操作视频识别成设备自动化，称已能慢速试跑，没达到百台手机和电脑无人办公的目标。可以把确认过的动作固定成脚本，再分别改识别、调度和设备执行。一次让豆包做调度，它直接去执行，就是职责边界没分清。直播跑题时，有人请带真实产品的人上麦，重新问到 AI 硬件实际用途，短暂拉回了业务讨论。想找 FDE 圈子的人也说只刷到少数聊天室，先关注参与者再沿同领域用户找，比估平台有多少直播间更实用。

## 采购总包的问题从去哪找客户，变成有什么值得卖给老客

多年做 B 端采购和 C 端积累的人以前与企业签年度框架，按期一起结算。从办公室、门店和装修到替客户买小杂货都接。缺货时期，有稀缺货源发朋友圈就会有老客来问，这是采购能力和反复交付积起来的信任。供应商倒常换，有不交货甚至失联的经历。装修单变少、同业资质和案例更强，也遇到当地设服务商、缴社保、维持资质的要求。举过某项资质一年约十万的估算，如果没连续订单，算完可能不值得做。

其以往曾按约 20% 利润筛单，今年见过同行约 5% 仍接。商品数万 SKU 时团队难逐件定利润，曾用统一比例定价。另一人举高价值药品按货值比例收物流费、带保险的例子，这是不同业务。过去介绍东软等产品，自己签约再分包；后来厂商早已直接联系同一客户，转介的价值变薄。老客池仍在，才考虑做有价值的自家产品和内容。入口和商品也得配，陌生渠道来的人可能没有信任。一次首店装修亏约两万、后来靠类似订单挣回，只是其拿来说明试做前先想清能承担多少学习成本的经验。

## AI 误上架造成扣款，测试时须先管住生产写入

做设计的人原以为 UI 做完以后实现很轻松，亲手试做才看到后台四百多次测试，要检查按钮和逻辑。另一次电商测试，他以为商品全下架了，Agent 却上架了不该上的商品，后台未提醒，发现前一直扣款。能打开页面只说明工具能运行。这个测试直接改了店里的商品状态，后台没有提醒，扣款发生后才被发现。采购的另一项自动化是按供应商能供的品类和客户需求匹配，有人做服务端分析，强调不把无关内容发给老客。每单只赚一元也做、十万元成本降到三万等都是他们的假设，未算作上线收益。

## 小企业老板只想把材料整理成固定输出

一位非技术参与者给认识的小企业老板做助手，下载开源模型，让模型帮做界面，再输入业务资料，按固定范式提炼。本人说界面够用，没透露报价和是否付费。有人愿意花钱省研究时间，交付简单也可能解决真实问题。同样，容易搭的功能也容易替代。有人用 Photoshop 抠图的旧经验进入动漫、人设和音乐试作，能出样品后还要看熟手是否也能提速，差异是否仍在业务流程或能否卖出去。配置 GPT、豆包等基础工具的价格和单量仅是现场举例。

## 共享充电宝铺早了，商家让他们收回来

有人自述第一年投共享充电宝，顾客不知道怎么用，商家嫌占地方还耗电，打电话叫他们取回。两年左右普及起来后，他称项目赚到钱，没讲完整投放和收益账。另有人拿 MCN、短剧的热点期比较，启动晚可能已经挤满同类，启动早则得有资源熬到需求出来。现场的六个月窗口和未来五年不适用别的行业。能用 AI 先做草稿再找专业人员，可减少花钱后才发现双方在想不同东西的风险；专业交付本身还要看需求、质量和有没有客户付费。

## 一期节目多平台发布，先看样片达标再放量

一支给自家业务做短视频和公众号的内容团队，人员类似自媒体，一个节目会上多媒体渠道。基础岗用桌面工具准备小红书和公众号素材，口播的具体工具名不够清晰。有人用豆包做提示词，也提到不同视频生成和代码工具各按工作用；没有给到可比较的结果。同一个人把一项工作做快，与把财务、市场、门店的任务真正接起来是不同的事，现场举十万变一万等效率数字时没有真实账单可对照。AI 内容有人看，也有流量差的，先定基本质量，再按渠道和产量看反馈。对下一步赛道，有人把线上适合反复执行的任务和线下需要人在场的服务分开看，银发服务是他关注的方向之一，还没有立项。十条火两条或一百条火两条是比方，不是统计结果。
